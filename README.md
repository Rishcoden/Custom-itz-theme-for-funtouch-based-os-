# Funtouch OS 3.0 Serenity Theme Port

A **Serenity theme port for newer Funtouch OS versions**, based on the original Serenity theme from **Funtouch OS 3.0**.

I extracted the original theme resources from the **SystemUI APK of a Vivo V5 running Funtouch OS 3.0**, then customized and tweaked the theme so it could be used on **Funtouch OS 10.5 and older versions**.

Along the way, I also modified the **icons, folders, and dynamic clock-style icon** to give the theme a more consistent look on newer Funtouch OS versions.

## Features

* Serenity theme based on Funtouch OS 3.0
* Ported for Funtouch OS 10.5 and below
* Customized app icons
* Modified folder appearance
* Dynamic clock-style icon
* Tweaked theme resources for compatibility with newer Funtouch OS versions

## Installation

### 1. Download the theme

Download the ZIP from this repository or clone the repository:

```bash
git clone <repository-url>
```

### 2. Create the `.itz` file

Extract the downloaded ZIP and compress the theme contents into:

```text
serenity.itz
```

Make sure the contents are compressed correctly and that you don't accidentally create an extra folder level inside the archive.

### 3. Open the theme directory

Using **ES File Explorer** or **ZArchiver**, make sure **hidden files are enabled**.

Navigate to the Funtouch OS theme directory:

```text
.dwd/b/b/k/t/h/e/m/e/s/
```

The folder structure should look similar to:

```text
.dwd/
└── b/
    └── b/
        └── k/
            └── t/
                └── h/
                    └── e/
                        └── m/
                            └── e/
                                └── s/
                                    └── serenity.itz
```

### 4. Copy the theme

Paste the newly created:

```text
serenity.itz
```

into the above directory.

### 5. Apply the theme

Open the **Themes** app on your Vivo device and look for the Serenity theme.

Apply it and enjoy the port.

## Compatibility

This port was customized with **Funtouch OS 10.5 and below** in mind.

Compatibility may vary depending on the Vivo device and Funtouch OS build, since theme handling and SystemUI resources can differ between versions.
